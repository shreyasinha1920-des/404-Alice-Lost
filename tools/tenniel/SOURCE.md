# Tenniel plates

Original 1865 engravings by John Tenniel for *Alice's Adventures in Wonderland*, public domain.
Downloaded from Wikimedia Commons, files named `Alice par John Tenniel NN.png`
(https://commons.wikimedia.org/wiki/Category:John_Tenniel%27s_illustrations_of_Alice%27s_Adventures_in_Wonderland).

`tools/tint-plates.mjs` turns these into the hand-tinted plates in `public/illustrations/`,
using the wash shapes in `tools/plates.json`.
